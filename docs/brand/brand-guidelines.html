01 — Logo

Logo

The Eagle mark combines a radar/concentric ring motif with a sharp diamond eye shape at center. The gold pupil represents precision targeting — the moment a threat is identified. The concentric rings symbolize continuous monitoring across all layers.

Variants

Primary — Dark background
Eagle
Mark + Wordmark
Light background (rare use)

Clearspace

Always maintain a minimum clearspace of 1× the logo mark's width around the logo. This ensures legibility and visual breathing room.

1× 1× 1× 1×

Minimum Size

The logo mark should never appear smaller than 24×24px in digital or 8mm in print. At small sizes, fine ring detail is lost — use the simplified mark (diamond + pupil only) below 24px.

Logo Do / Don't

✓ Do
Use official colors on dark backgrounds
✗ Don't
Rotate, recolor, or distort the mark

04 — Spacing System

Spacing System

Eagle uses a 4px base grid. All spacing values are multiples of 4. This creates consistent vertical and horizontal rhythm throughout the interface.

Scale Tokens

--space-xs 4px
--space-sm 8px
--space-md 16px
--space-lg 24px
--space-xl 32px
--space-2xl 48px
--space-3xl 64px
--space-4xl 96px
--space-5xl 128px

Usage Guidelines

Component internal padding: Use --space-md (16px) to --space-xl (32px). Cards use --space-lg or --space-xl.

Between related elements: --space-sm (8px) to --space-md (16px). Example: icon to label, title to description.

Between sections: --space-4xl (96px) to --space-5xl (128px). Major page sections need generous breathing room.

Grid gaps: --space-md (16px) to --space-lg (24px). Card grids use 24px gaps.

CSS Token Usage

/* Use CSS custom properties — never hardcode pixel values */
padding: var(--space-xl);
gap: var(--space-lg);
margin-bottom: var(--space-md);

07 — Voice & Tone

Voice & Tone

Eagle speaks with the confidence of a product that works. No hype, no superlatives, no vague promises. We describe what Eagle does in precise, technical terms — because our users are technical professionals who respect clarity over polish.

Voice Principles

Confident — We state facts. We don't hedge. "Eagle scores every alert" not "Eagle can help score alerts."

Precise — Use specific numbers and technical terms. "<100ms P95 latency" not "blazing fast."

Respectful — SOC analysts are elite. We don't talk down. We don't explain what a SIEM is.

No fluff — Every word earns its place. If a sentence doesn't add information, cut it.

On-Brand vs Off-Brand

✓ On-Brand
"Eagle scores every alert in <100ms using 5 specialist XGBoost models. True positives surface immediately. False positives are suppressed with explainability."
✗ Off-Brand
"Eagle leverages cutting-edge AI/ML technology to revolutionize the way your team handles security alerts with our next-generation platform!"
✓ On-Brand
"Connect any source. Kafka-native ingestion, OCSF normalization. Your entire security stack in one schema."
✗ Off-Brand
"We're excited to announce that Eagle seamlessly integrates with your favorite security tools, making it easy to get started!"
✓ On-Brand
"Your analysts are drowning. 10,000 alerts per day. Half are noise. Eagle fixes this."
✗ Off-Brand
"In today's ever-evolving threat landscape, security professionals face unprecedented challenges that require innovative solutions."
08 — Do / Don't

Do / Don't

Six rules for applying the Eagle brand consistently.

Use dark backgrounds

Eagle lives in darkness. The deep navy palette conveys security and sophistication. Always use --abyss or --void as your base.

Eagle on dark
Use light/white backgrounds

White or light gray backgrounds undermine the brand's authority. The only exception is light-mode logo usage in partner contexts where required.

Eagle on light ✗
Use specific numbers

Quantify everything. "70% reduction" not "significant reduction." "<100ms" not "near-instant." Our audience respects data.

<100ms P95 · 10K+ alerts/day · 5 models
Use vague marketing speak

Avoid "revolutionary," "next-gen," "game-changing," "seamless," and "cutting-edge." These are noise. Our users filter noise for a living.

blazing fast · revolutionary · best-in-class
Maintain generous spacing

Breathing room conveys confidence. Sections need 96–128px padding. Cards need 24–32px internal padding. Dense UIs feel cheap.

Mix brand colors with off-palette colors

Stick to the defined palette. No neon greens, purples, pinks, or off-palette blues. The constrained palette is the brand.

✗ Off-palette
